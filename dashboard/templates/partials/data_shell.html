{# Persistent across the panel's 4s auto-refresh (it lives outside #data-panel-inner), so an open preview survives a poll tick. Populated by hx-get requests from extraction table rows in partials/data_panel.html — the graph view itself renders inline in the panel, not through this modal. Fixed centering (top-1/2 left-1/2 + translate) rather than relying on the native auto-centering: Tailwind's preflight zeroes out `margin` on every element, which breaks the UA stylesheet's `margin: auto` centering trick dialogs normally get for free. `hidden open:flex`, not a bare `flex` — a plain `dialog:not([open]) {display:none}` rule only exists in the browser's user-agent stylesheet, and author CSS (any Tailwind display utility, even at equal or lower specificity) always outranks user-agent CSS. An unconditional `flex` class would defeat the browser's native close/hide behavior: closing the dialog (Escape, backdrop click, the X button) clears the `open` attribute and drops it from the modal top layer, but it stays fully painted on screen since nothing tells it to stop being `display:flex`. Tailwind's `open:` variant targets `[open]` directly, so display tracks the dialog's actual open state instead of being permanently on. #}
